## 📂 Project Structure & Modules

The repository is organized into various modular tools, each handling a specific utility task:

* **`converter/`**: General-purpose conversion utilities.
* **`currency and stockMarket/`**: Tools to track currency exchange rates and stock market data.
* **`insta/`**: Instagram-related automation and utility scripts.
* **`ip/`**: Network and IP address utility tools.
* **`map/`**: Map and geographical location helpers.
* **`pdf/`**: PDF manipulation and processing utilities.
* **`spoti/`**: Spotify-related command-line tools.
* **`unitConverter/`**: Quick unit conversion tool (measurement, weight, etc.).
* **`visual/`**: Image and visual processing utilities.
* **`wheather/`**: Terminal-based weather forecasting tools.
* **`wp/`**: WhatsApp or WordPress utility scripts.
* **`youtube/`**: YouTube media downloading and management tools.
